# Texture

**Open textbooks, written by the world's best educators, free for every student.**

Texture is a nonprofit organization (in formation) that produces open-source,
openly licensed textbooks — starting with the K-12 core curriculum, expanding
to higher education — and builds **txt**, a git-based collaborative
typesetting tool that powers the work.

- **Free digital editions** of every book, forever, under CC BY 4.0.
- **Print editions at the lowest sustainable cost.**
- **txt**: version control, structured review, and professional typesetting
  for books, built on git.
- **The Texture platform**: where leading educators collaborate to write,
  review, and publish.
