Open textbooks, written by the world's best educators, free for every student.

Texture builds open-source, openly licensed textbooks — K-12 core curriculum first, then higher education. Digital editions are free forever. Print costs what printing costs.

Books as source code: every Texture book is a git repository, every change is reviewed by credentialed educators, and every format is built from the same file — accessibility checked at build time.

Free is the feature. Rigor is the guarantee.

✓ Open, forever

Every book is CC BY 4.0 — read, adapt, translate, and redistribute without asking. Even if Texture disappeared tomorrow, the books stay free.

✓ Reviewed like it matters

Anyone can propose a change; nothing ships without subject-matter review, pedagogy review, and copy editing. Editors sign every edition, and the full review history is public.

✓ Living books

A teacher reports an error today; it's fixed in the next build — days, not editions. Print owners can see exactly what changed since their printing.

How a Texture book gets made

txt is our open-source typesetting tool: git-based version control for books, structured editorial review, and automated professional typesetting. Educators work in a browser; the toolchain guarantees that what was reviewed is what gets printed.

propose → txt check ✓ → review (subject · pedagogy · copy) → merge → build → web · pdf · epub · print
